Where to get the source code of the GPL programs
------------------------------------------------
- yt-dlp:      https://github.com/yt-dlp/yt-dlp (release tags match the build)
- FFmpeg 6.1.1 (ffmpeg.exe): https://github.com/FFmpeg/FFmpeg/commit/e38092ef93
               (commit named by the Gyan Doshi build; builds and notes:
               https://www.gyan.dev/ffmpeg/builds/)
- FFmpeg 6.1.1 (ffprobe.exe): same source as ffmpeg.exe (same build)
- FFmpeg 9.0.2 (macOS ffmpeg and ffprobe): https://ffmpeg.martin-riedl.de
               (the page of the build lists the source and the build options;
               project: https://github.com/FFmpeg/FFmpeg)
- The programs are delivered unchanged, as published by those projects.
- If you cannot get the source from those places, ask on the EasyTube
  project page and it will be provided.

This is a plain-language summary, not legal advice. In case of doubt, the
full license texts in this folder are what counts.
